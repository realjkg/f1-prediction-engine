# Two-run determinism evidence

Milestone 1 acceptance gate: **two `make demo` runs produce identical prediction
records and metrics.** This file records the run that proves it.

- Date: 2026-10-10
- Base commit: `685d7bb` (`origin/main`, all build PRs #1–#10 merged)
- Mode: fixture race brief (no Ollama configured → no live-model nondeterminism)

## Method

1. `make engine-install` + `make web-install` once, then two back-to-back
   `make demo` invocations, each in a fresh OS process (its own `tmux` session);
   the uvicorn server was killed after each run's evidence was written.
2. The ledger at `data/ledger.jsonl` (gitignored — regenerated by every run)
   was snapshotted after each run and compared byte-for-byte.
3. The demo itself deletes and regenerates the ledger per run, so each
   snapshot is that run's complete evidence output (24 prediction records +
   1 backtest record; 2024 season, 24 scoreable rounds).

dataset and fixed seeds only; wall-clock time and durations never enter
evidence (`generatedAt` is the dataset's pinned provenance timestamp).
